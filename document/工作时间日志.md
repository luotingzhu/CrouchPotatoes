## 四、典型问题与处理（用于复盘）

| 问题 | 现象 | 处理 |
|---|---|---|
| 注册报错不可读 | 前端显示 `[object Object]` | 统一错误格式化，按 pydantic 类型翻译 422 校验信息 |
| 抓取后无法生成报告 | 订阅模块 72h 内无数据 | 回退最新历史数据 + 明确提示过时模块与建议订阅模块 |
| 报告仅覆盖新闻 | 高产新闻源挤占低频宏观数据 | 改为按模块配额取数后再按时间合并 |
| 问答「失效」 | 接口 500，日志 `redis ConnectionError` | 定位 WSL 空闲关机；`start.ps1` 加双容器健康检查 + WSL 常驻进程 |
| 手机端错位 | 侧栏占宽、表格与长链接溢出、点会话无反馈 | 新增窄屏断点：导航横滑、表格内滚动、长链接断行、会话列表限高并自动滚动 |
| 回答出现 `**` | 模型输出 Markdown，前端按纯文本渲染 | 输出统一清洗 + 提示词禁用 Markdown |
| 内网穿透受阻 | 国内节点 501（禁明文 HTTP）、HTTP 隧道 403（需自有域名/备案） | 结论：TCP + 境外节点；或本地 HTTPS；或后续改用自有域名 |
